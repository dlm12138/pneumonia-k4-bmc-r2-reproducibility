# What is and is not reproducible from this package

1. Public tables, source provenance, scientific functions and synthetic checks can be inspected without any patient access. Synthetic checks test implementation properties, not reproduction of real study estimates.
2. Given legally obtained **correctly prepared original study inputs**, including saved labels, outcome evidence, strict eligibility and saved folds, the included actual association and prediction implementations support recalculating downstream results. Access to raw databases alone does not supply these intermediate files.
3. Exact frozen assignment requires the withheld numerical assets. Parameter-dependent coverage, marginal likelihood, Mahalanobis, early assignment, posterior and time-order analyses require both those assets and original/historical feature inputs. No replacement fit is supplied.
4. SQL queries for pulse oxygen and support checks are included for all three sources. Historical cohort and hourly-vital extraction uses Python and private historical inputs, rather than three standalone SQL files. This is not a complete raw-to-paper SQL pipeline.
5. Historical candidate construction, event-evidence assembly, comorbidity recovery and saved-fold assembly programs are included in source_history. They document the production logic but do not distribute all private manifests, original reference inputs, saved folds and numerical assets; the public-only pipeline is therefore not self-contained. Some study drivers stop if required inputs or validation tables are absent. An input contract is not a supplied data file.
6. Original derivation, K selection, stability, mixture training and finalisation source is included under code/source_history/historical_model. It is inspection-only by default. Current application analyses use the original frozen model, whose numerical assets remain withheld. A new fit is not a reproduction of the original frozen object.
7. The R competing-risk programs retain their original private event/design and aggregate validation prerequisites. Their syntax and mathematical sources can be reviewed, but this package alone is insufficient to execute the entire R workflow on real data.
8. The clinical characterization functions are the historical general functions. Current aggregate tables include the audited oxygen replacement, recovered MIMIC comorbidity descriptions and corrected eICU support scope. Re-running the general characterization function on an uncorrected frame will not recreate those tables. Input column mapping and scope labelling are prerequisites, not new estimates.

This is a transparent **partial, conditional reproducibility release**, not a one-command independent raw-database replication. Missing prerequisites and inaccessible numerical parameters remain genuine limitations. A successful syntax or synthetic check must not be called a clinical or end-to-end validation.
