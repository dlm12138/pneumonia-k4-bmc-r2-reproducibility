# Database access

The actual source versions are MIMIC-IV 3.1, MIMIC-III 1.4 and eICU-CRD 2.0. These are not replaced by demo datasets or newer versions.

| Source | Official project and application route | Version DOI |
| --- | --- | --- |
| MIMIC-IV 3.1 | https://physionet.org/content/mimiciv/3.1/ | https://doi.org/10.13026/kpb9-mt58 |
| MIMIC-III 1.4 | https://physionet.org/content/mimiciii/1.4/ | https://doi.org/10.13026/C2XW26 |
| eICU-CRD 2.0 | https://physionet.org/content/eicu-crd/2.0/ | https://doi.org/10.13026/C2WM1R |

Each researcher must obtain their own PhysioNet credentialing approval, complete the required training and sign the applicable project data use agreement. Consult each project's current access section; access is not transferred by possession of this code. General official guidance: https://physionet.org/about/faqs/ and https://physionet.org/about/citi-course/ .

This package does not redistribute any patient-level raw or derived data. Do not upload locally generated cohort, feature, assignment, outcome, prediction, timestamp or conflict files. File and column names describing source schemas in the code are not individual identifier values.

The official MIMIC-IV page contains specific guidance on derived datasets and models. This package excludes the fitted numerical assets; it does not imply that credentials alone authorise redistribution of such assets. Public statistical summaries are distinct from a releasable frozen numerical model. Institutional and database-policy review remains the authors' responsibility.

The official access policies and source-version pages were checked on 2026-10-15. Credentials, passwords and authentication files are not included or required in code examples.
